# MdWallateTransfer
# live link
https://htmlpreview.github.io/?https://github.com/raushxit/MdWallateTransfer/blob/main/index.html

A responsive, functional front-end simulation inspired by the supplied screenshots.

## Important
This is a demo/simulation. It is not affiliated with TikTok and does not connect to TikTok, process real coins, or make real payouts.

## Included interactions
- Mobile-first dashboard with animated balance decrement
- Exchange screen
- Real-time TikTok creator lookup via `https://api.nftoken.info/api/tiktok/profile/{username}`
- Live avatar image, display nickname, @handle, follower count, and like count
- Red-tinted `@your-TikTok Handle` placeholder matching the red `@` symbol
- Natural decreasing balance animation (numbers turn red while counting down, then smoothly transition back to black)
- 250 / 500 / 15,000 coin presets with active indicators
- Custom coin keypad with live dollar conversion
- Exchange completion screen with recipient profile card
- TikTok Start Gifter Level card with official TikTok tile logo
- Transaction history with real recipient avatars
- Disabled/clearly simulated withdrawal action

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

For production deployment, upload the folder to a static host such as Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
